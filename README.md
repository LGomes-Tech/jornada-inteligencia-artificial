# 🤖 Jornada em Inteligência Artificial

Este repositório documenta minha jornada de estudos e desenvolvimento em **Inteligência Artificial utilizando Python**.

O objetivo é sair dos fundamentos de programação e chegar ao desenvolvimento de aplicações práticas utilizando:

* Python
* NumPy
* Pandas
* Matplotlib
* Scikit-learn
* Machine Learning
* Deep Learning
* LLMs
* Embeddings
* Bancos vetoriais
* RAG
* LangChain
* Agentes de IA
* Automação com IA
