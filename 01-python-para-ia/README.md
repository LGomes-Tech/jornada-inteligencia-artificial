# 🐍 Python para Inteligência Artificial

Esta etapa apresenta os fundamentos de Python necessários para trabalhar com Inteligência Artificial.

## Conteúdos

* Variáveis
* Tipos de dados
* Strings
* Listas
* Tuplas
* Dicionários
* Condicionais
* Loops
* Funções
* Classes
* Arquivos
* Exceções
* Módulos
* Pacotes
* Ambientes virtuais

## Exercícios

### 01 — Variáveis

Introdução às variáveis e tipos de dados.

### 02 — Condicionais

Utilização de `if`, `elif` e `else`.

### 03 — Loops

Utilização de `for` e `while`.

### 04 — Listas e dicionários

Estruturas de dados utilizadas frequentemente em aplicações de IA.

### 05 — Funções

Criação e utilização de funções.

### 06 — Classes

Introdução à programação orientada a objetos.

## Objetivo

Ao terminar esta etapa, devo ser capaz de desenvolver pequenos programas em Python sem depender constantemente de exemplos prontos.
